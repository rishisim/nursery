# V7 scientific limitations

V7 is a synthetic package qualification, not a scientific experiment. Passing it cannot establish that BabyWorld data are learnable, that action sensing causes a language-learning improvement, or that any real-data effect will generalize.

The visual observations, utterance lexicon, sensor streams, null events, and factor schedule are hand-built. They test whether the package can represent weak and variable alignment, target absence, ambiguity, imperfect detector capacity, false positives, shifts, shuffled matching, and absent or corrupted channels without oracle leakage. They do not estimate the prevalence or difficulty of those phenomena in a real corpus.

Sensor-free identification is assessed under the declared synthetic observation geometry and common probabilistic scoring rule. Global-label and best-global-permutation diagnostics are reported separately, but finite synthetic success does not remove label or representation uncertainty in future data.

The sensor contribution is deliberately narrow: it can reinforce language-supported action semantics when the independently frozen detector agrees, but it cannot supply noun evidence and is not available at language-only evaluation. A passing synthetic contrast therefore supports only a raw-sensor-assisted weak lexical/action grounding qualification claim, not sensor necessity or ecological validity.

The excluded smoke is used once for package readiness. Future-development and confirmation identifiers remain untouched, and VERSION_READY authorizes neither registry.
