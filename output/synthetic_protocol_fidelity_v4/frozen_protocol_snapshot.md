# Frozen protocol: synthetic benchmark protocol-fidelity repair and qualification v4

Protocol ID: `synthetic-benchmark-protocol-fidelity-v4`. This is a fixture-only package qualification. It cannot produce a scientific GO/NO-GO result, authorize a development run, or authorize confirmation. V3's STOP remains in force, and v3 outcome values are not evidence for or against the scientific hypothesis because v3 did not execute its frozen implementation claims faithfully.

## Identifiability and corpus construction

The visible corpus contains only utterance tokens, cue-free candidate observations, event intervals, speech time, public factor values, and raw sensor streams. Intended concept indices, target event positions, ownership, lexical mappings, semantic labels, and evaluation answers exist only in separate oracle/key ledgers. The primary learner rejects a row containing any forbidden oracle field.

There are six action concepts formed by three primitives crossed with two manners. Every action episode has four unique candidates: the target and exactly one distractor from each possible relation cell (different primitive/different manner, different primitive/same manner, same primitive/different manner). Each concept receives 16 episodes, giving exactly 16 distractors in every relation cell for every concept. Candidate positions are exactly balanced.

There are six noun concepts. The noun target is always present, but sensor ownership is generated by the complete 4×4 factorial of target position and sensor-owner position independently within every noun concept. Thus target and each distractor opportunity have the same 1/4 structural ownership probability, and ownership has no dependence on noun identity. The primary learner applies zero sensor weight to nouns. A detector-score audit additionally checks the target-versus-distractor evidence gap without using that audit to tune the corpus.

The ambiguity is partially identifiable without sensors: primitive and noun mappings recur across balanced distractors, while exact relation-cell balance intentionally leaves the two global manner labelings symmetric. The learner therefore starts manner rows symmetrically and, in the no-sensor condition only, projects those unidentifiable rows back to the symmetric distribution rather than allowing iterative numerical asymmetry to report a global labeling or inversion as learned. This policy reads neither targets nor labels. The cue-free no-sensor action baseline must be strictly above chance floor but below ceiling on qualification fixtures, with unresolved manner ties reported transparently; failure is readiness failure, never permission to leak a target pointer.

## Joint learner and executable factors

The learner jointly fits all lexical rows over repeated iterations. Within an episode, each token normalizes over candidates plus a null candidate, while co-referring primitive and manner words also form a shared candidate-normalized responsibility. The competition weight mixes individual and shared assignment, so candidates compete for the complete compositional phrase without incorrectly forcing its component words onto different events. Across the vocabulary, column normalization applies a lexical exclusivity penalty before row normalization. Both configured iteration count and competition weight participate in the numeric update and are required to change a fixed fixture's model digest under perturbation.

Sensor logits enter only action primitive/manner assignments. Visibility changes the candidate observations themselves. Lag is derived only from visible speech time relative to the scene midpoint and multiplicatively attenuates the update; no target time is used. Factor results refit on the actual episodes at each visibility or lag level and store episode IDs, counts, model digest, predictions, and accuracy. Recomputing from persisted inputs must exactly reproduce every row. A pooled-copy row is invalid.

## Evaluation and controls

Prediction accepts only lexical prototypes and answer-free evaluation prompts. Scoring is a separate operation over prediction IDs and sealed keys; permuting keys cannot change predictions. The oracle-alignment control executes a fit from the separate oracle target positions. The direct-capacity control executes supervised prototype fitting from evaluation prompts and keys. Neither score may be assigned as a constant. Corrupting each control's input must reduce its score below its gate in a pre-freeze adversarial fixture test.

## Inference

The independent unit for any future scientific iteration is the corpus seed. For non-degenerate paired effects, v4 uses a fixed-resample studentized bootstrap and records the number of valid studentized resamples. If every observed effect is identical within tolerance, studentization is undefined. V4 then returns the exact empirical point-mass interval `[mean, mean]`, labels it `degenerate_point_mass`, sets `population_uncertainty_estimated=false`, and emits a limitation warning. This is not a fabricated bootstrap interval and cannot by itself support a population claim. Empty, non-finite, or otherwise invalid samples raise an error.

## Seed firewall and run order

Fixture, excluded-smoke, future-development, and confirmation registries are pairwise disjoint, and their union is disjoint from the explicit union of all v1-v3 seeds. Every generate, detector inference, fit, predict, score, read, summarize, control, and inference operation must obtain a purpose-specific firewall authorization and is logged whether allowed or blocked. During this task only `fixture_only` is allowed before freeze and `excluded_smoke` after freeze. Future-development, confirmation, and prior seeds are blocked for all operations.

After fixture tests pass, the config, protocol, primary sources, source package, runner, tests, registries, gates, and traceability matrix are frozen by content hash and copied to a snapshot area. Exactly one excluded-smoke qualification is run. A second isolated execution is a reproduction of that same excluded run, not a new scientific outcome. Deterministic core artifacts must have identical file sets, bytes, and per-file hashes. Timestamp/path metadata is isolated and excluded with an explicit ledger. No post-smoke patch or rerun is allowed.
