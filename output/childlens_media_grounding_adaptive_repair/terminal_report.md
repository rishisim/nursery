# ChildLens media-grounding adaptive repair terminal report

**Decision: `NO_GO_ADAPTIVE_MEDIA_REPAIR`**

The ordinary environment failures were repaired and Blender now meets the
bounded physical measurement contract. The environment is nevertheless not
scientifically ready for the final cue-lift experiment, which was not launched.

TDW's Python and `pkg_resources` failures were repaired with a pinned Python
3.11 environment. The official build launched, but repeated native and Rosetta
runs stalled after the controller handshake and before the first scene response.
Blender 4.2.1 LTS arm64 was therefore selected on pre-outcome reliability
evidence. Its deterministic bounded episode emitted RGB, depth, segmentation,
transforms, an evaluated articulated joint, timestamped action commands,
pose-derived proprioception and IMU, exact evaluated-geometry contact, and a
playable MP4 on one clock. Positive contact, negative no-contact, dynamic
joint/IMU, and static quiet controls passed.

Anna `de_DE` emitted deterministic, playable, unclipped German WAV, and the
pinned official egobabyvlm interfaces completed tiny CPU and MPS
train/backprop/eval smoke tests.

The terminal blocker is scientific rather than an ordinary dependency. The
retained public ChildLens calibration summary pools all 18 development
participants. The frozen folds exist only as a hash, while the clean V5 process
intentionally removed its restricted fold-level feature material. Therefore a
new generator cannot be tuned on calibration participants and honestly assessed
on participant-disjoint evidence. Back-solving fold targets from the pooled
summary or assessing against the same pooled targets would violate the frozen
measurement contract.

No generator fitting, calibration scoring, oracle control, destroyed-mapping
control, or synchronized/shuffled/shifted/uninformative/absent cue arm ran. The
22 locked participants remained sealed, and no AEA or BabyView input was used.

Bounded next options:

1. Restore the exact hash-bound restricted V5 fold features from an approved
   secure backup, then resume from the frozen amendment.
2. Separately authorize exact bounded reacquisition/re-extraction of the same 58
   development recordings and no others, using the existing frozen folds and
   extractor hashes.
3. Retain this no-go and do not pursue the cue-lift experiment.
